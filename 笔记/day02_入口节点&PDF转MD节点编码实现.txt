07-掌柜智库_MinerU介绍

    https://mineru.net/
    https://github.com/opendatalab/MinerU/blob/master/README_zh-CN.md

        1.MinerU 是一款文档解析工具，可将 PDF、图片以及 DOCX、PPTX、XLSX 转化为机器可读格式（如 Markdown、JSON），
            便于后续检索、抽取与二次处理

        2.主要功能
            支持 PDF、图片与 DOCX、PPTX、XLSX 输入
            删除页眉、页脚、脚注、页码等元素，确保语义连贯
            输出符合人类阅读顺序的文本，适用于单栏、多栏及复杂排版
            保留原文档的结构，包括标题、段落、列表等
            提取图像、图片描述、表格、表格标题及脚注
            自动识别并转换文档中的公式为LaTeX格式
            自动识别并转换文档中的表格为HTML格式
            自动检测扫描版PDF和乱码PDF，并启用OCR功能
            OCR支持109种语言的检测与识别
            支持多种输出格式，如多模态与NLP的Markdown、按阅读顺序排序的JSON、含有丰富信息的中间格式等
            支持多种可视化结果，包括layout可视化、span可视化等，便于高效确认输出效果与质检
            内置命令行、FastAPI、Gradio WebUI，支持本地编排和多服务部署
            支持纯CPU环境运行，并支持 GPU/MPS加速，以及十余款国产算力平台的推理加速
            兼容Windows、Linux和Mac平台

        3.在线体验

        4.安装MinerU（requirements.txt已经安装过了，省略）

            pip install --upgrade pip -i https://mirrors.aliyun.com/pypi/simple
            pip install uv -i https://mirrors.aliyun.com/pypi/simple
            uv pip install -U "mineru[all]" -i https://mirrors.aliyun.com/pypi/simple

        5.笔记\MinerU课件

                auto-engine-hybrid 本地混合引擎  默认

    如果您的设备满足上表中GPU加速的条件，可以使用简单的命令行进行文档解析: 默认hybrid混合方式。会用到GPU，没安装CUDA版的Pytorch会报错。

            命令及选项：

                mineru-models-download
                   Please select the model download source:  (auto, huggingface, modelscope) [auto]:
                   Please select the model type to download:  (pipeline, vlm, all) [all]:
            含义：

                mineru[all] = mineru[pipeline] + mineru[vlm] + mineru[web] + ...
                mineru[pipeline] — 本地 8 个小模型（Layout、OCR、MFD、MFR 等）+ torch
                mineru[vlm] — 视觉语言模型（MinerU2.5-Pro）
                mineru[web] — FastAPI + Gradio WebUI

                GET  /tasks/{id}/result   — 获取解析结果（ZIP包）
                GET  /health              — 健康检查

10-掌柜智库_subprocess子进程调用

    #    mineru -p E:/doc/万用表RS-12的使用.pdf -o E:/doc/output/ --source local  --backend  pipeline

    proc = subprocess.Popen(
        args=["mineru", "-p", r"E:/doc/万用表RS-12的使用.pdf", "-o", r"E:/doc/output/", "--backend", "pipeline"],
        stdout=subprocess.PIPE,  # 捕获标准输出
        stderr=subprocess.STDOUT,  # 合并错误到标准输出
        text=True,
        encoding="utf-8",
        errors="replace",  # 遇到乱码时替换
        bufsize=1  # 行缓冲，实时输出
    )

    for line in proc.stdout:
        print(line.rstrip())

    return_code = proc.wait()
